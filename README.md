# MotoScan

MotoScan is a Flutter catalog and marketplace app for motorcycles, parts, and accessories. It includes a public browsing experience for riders and a Firebase-backed dashboard for shop owners.

## What the app does

- **Home catalog** — browse parts, accessories, maintenance supplies, and a curated design gallery.
- **Search** — filter the parts library by name, category, and description, including live shop inventory.
- **Motorcycle gallery** — view 50 models / 74 variants with zoomable images and per-variant part lists.
- **Parts by motorcycle** — drill down by brand, model, and variant.
- **Shop tab** — public marketplace listing shop profiles, locations, products, prices, stock, and categories, with links to Shopee and Lazada.
- **Buy options** — show matching in-stock local shops first, then marketplaces.
- **Scan tab** — capture or upload a photo for preview. AI part recognition is intentionally not connected yet; the UI states this limitation.
- **Shop owner dashboard** — create and edit a shop profile, add products, edit product name/category/description/price/quantity/image URL, delete products, delete a shop, and sign out.

## Authentication model

Shop owners sign in with **Firebase Email/Password** authentication. Public browsing does not require an account.

There is **no OTP, MFA, email-verification gate, custom-token flow, or Cloud Functions backend** in this project. The Firestore OTP, rate-limit, audit, and session collections were removed.

If Firebase is not configured, or the current platform is not registered in `lib/firebase_options.dart`, the app falls back to an **in-memory demo store**:

- Shop: `MotoScan Demo Parts`
- Owner login: `demo@motoscan.test` / `demo1234`
- All demo data resets when the app restarts.

Do not use a real password in demo mode.

## Setup

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

### Firebase

1. Create or select a Firebase project.
2. Run `flutterfire configure` so `lib/firebase_options.dart` and `.firebaserc` point at your project.
3. In the Firebase console, enable **Authentication → Email/Password**.
4. Deploy the rules and the web build:

```bash
firebase deploy --only firestore:rules
flutter build web
firebase deploy --only hosting
```

## Tests and CI

GitHub Actions runs `flutter analyze` and `flutter test` on pushes and pull requests via `.github/workflows/ci.yml`.

## Assets
